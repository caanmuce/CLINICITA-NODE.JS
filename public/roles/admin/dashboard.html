¿Cómo se calcula el ausentismo?

Inasistencias ÷ (citas atendidas + inasistencias) del mes. Solo cuentan las citas que ya ocurrieron y el médico registró; las pendientes, futuras y canceladas no entran, para no bajar el porcentaje de forma artificial.
